WhatsApp Order Site - பயன்படுத்தும் முறை
=========================================
1. admin.html-ஐ browser-ல் திறக்கவும் -> கடை விவரம், பொருட்கள் மாற்றவும் -> "config.js பதிவிறக்கு".
2. வந்த config.js-ஐ இந்த folder-ல் உள்ள config.js மேல் replace செய்யவும்.
3. index.html-ஐ திறந்து test order அனுப்பிப் பாருங்கள்.
4. GitHub Pages / Netlify / Cloudflare Pages-ல் இந்த folder-ஐ upload செய்தால் online.

வேறு கடைக்கு: shops/grocery.js போல ஒரு file-ஐ config.js ஆக copy செய்து admin.html மூலம் மாற்றவும்.
புதிய வசதி சேர்க்க: js/app.js (logic), css/style.css (design), config.js (தகவல்).
